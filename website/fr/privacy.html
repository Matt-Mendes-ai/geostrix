Confidentialité

GeoStrix est une application de bureau qui fonctionne sur votre propre ordinateur. Elle n'a ni compte, ni connexion, ni outil d'analyse ou de télémétrie d'aucune sorte. Cette page décrit GeoStrix 0.2.7 et ce site web.

Ceci est une traduction de la politique de confidentialité en anglais. En cas de différence entre les deux versions, la version anglaise fait foi.

Ce que GeoStrix collecte

Rien. GeoStrix ne collecte, n'envoie et ne stocke aucune information personnelle, donnée d'utilisation, rapport de plantage ni télémétrie. L'application ne contient aucun code d'analyse, et aucun serveur de ce projet ne reçoit de données de sa part.

Rapports de problème. Aide → Signaler un problème crée un fichier zip dans votre dossier Téléchargements — ce que vous avez écrit, une image de la fenêtre de GeoStrix, les caractéristiques de votre système (versions, système d'exploitation, mémoire, carte graphique), les messages d'erreur récents (y compris les plantages d'écran des sessions précédentes, que GeoStrix conserve dans un petit fichier de son propre dossier de données sur votre ordinateur) et, si vous laissez la case cochée, le journal récent du moteur Python. Votre projet n'est inclus que si vous cochez cette option. GeoStrix n'envoie rien : il ouvre un courriel dans votre propre logiciel de messagerie, et le rapport ne part que si vous le joignez et l'envoyez.

Où se trouvent vos données

Les données de votre projet — collets, mesures de déviation, descriptions, analyses, rasters et tout ce que vous importez — restent sur votre ordinateur : dans le fichier de projet que vous enregistrez, et dans un fichier d'enregistrement automatique dans le dossier de paramètres de GeoStrix. Elles ne sont jamais envoyées nulle part.

Mots de passe des bases de données. Par défaut, un mot de passe saisi dans Se connecter à la base de données n'est utilisé que pour la session en cours. Si vous cochez Mémoriser le mot de passe sur cet ordinateur, il est enregistré chiffré par le système d'exploitation (sous Windows, lisible uniquement par votre compte Windows sur cet ordinateur), dans le dossier de paramètres de GeoStrix — jamais dans le fichier de projet. L'oublier le supprime.

Comme lors de la visite de n'importe quel site web, ces requêtes montrent votre adresse IP au service contacté, qui a sa propre politique de confidentialité. Aucun identifiant vous concernant ou concernant votre projet n'est envoyé, sauf la clé d'API Tracestrack que vous saisissez pour le fond de carte topographique : elle part chez Tracestrack avec chaque tuile et est liée à votre compte Tracestrack. Le correcteur orthographique intégré est désactivé, donc aucun dictionnaire n'est téléchargé. Si vous n'utilisez aucune de ces fonctions, GeoStrix n'établit aucune connexion réseau.

Le moteur Python utilisé pour la modélisation et les inversions, ainsi que le module optionnel de modélisation prédictive, fonctionnent sur votre ordinateur, n'écoutent que sur 127.0.0.1 et n'établissent aucune connexion sortante.

Accès des applications d'IA (facultatif, désactivé par défaut)

Outils → Accès des applications d'IA permet à une application d'IA que vous utilisez déjà (par exemple Claude Desktop) de lire le projet ouvert dans GeoStrix : les sondages et les champs de leurs collets, les teneurs des analyses, les intervalles décrits, les coupes, des statistiques de teneur et les meilleures intersections. Elle ne peut ni ouvrir des fichiers, ni voir un chemin de fichier, ni utiliser un mot de passe, et ce qu'elle demande se limite à une page de lignes à la fois.

Modifications (facultatif, désactivé par défaut). Un second interrupteur, Autoriser les applications d'IA à apporter des modifications, permet à l'application de faire aussi une partie de ce que font les boutons de GeoStrix : colorer les sondages, afficher ou masquer des couches, orienter la vue, ajouter une coupe, ajouter une page de mise en page (une feuille en un clic ou un tableau des meilleures intersections), construire une surface de modèle, un filon, un halo d'altération ou une enveloppe de teneur à partir de vos journaux et dosages (le même « Construisez-le pour moi » que dans StrixViewer, visible pendant son exécution et annulable là), estimer des teneurs dans un modèle de blocs dans la boîte de dialogue Estimation des teneurs, ajouter les blocs du dernier modèle ou les cellules de la dernière enveloppe de teneur comme modèle de blocs, et télécharger une image satellite ou un terrain pour la zone du projet. Chaque modification s'affiche dans GeoStrix au moment où elle se fait, avec un bouton Annuler. Une application d'IA ne peut rien supprimer ni écraser, ni enregistrer le projet, écrire un fichier ou modifier les réglages de GeoStrix. Chaque téléchargement est demandé dans GeoStrix, à chaque fois, et n'a lieu que si vous dites oui ; il va aux mêmes services publics, avec les mêmes données envoyées (l'emplacement de la zone), que lorsque vous appuyez vous-même sur le bouton.

Ce que l'application d'IA reçoit quitte GeoStrix. Les réponses vont à cette application, puis au fournisseur d'IA qu'elle utilise (par exemple Anthropic pour Claude), selon les conditions et la politique de confidentialité de ce fournisseur. N'activez cette fonction que pour un projet que vous pouvez partager avec ce fournisseur. Le lien entre GeoStrix et l'application d'IA n'utilise aucune connexion réseau : c'est un canal privé sur votre ordinateur (aucun port réseau), protégé par un code renouvelé à chaque démarrage de GeoStrix.

Elle est désactivée par défaut ; elle s'éteint à la fermeture de GeoStrix sauf si vous cochez Le garder activé au redémarrage de GeoStrix ; GeoStrix vous demande la première fois que chaque application d'IA se connecte ; la barre d'état l'indique tant qu'elle est active, et la fenêtre liste tout ce que l'application a demandé ; vous pouvez l'arrêter à tout moment. L'interrupteur des modifications se désactive avec l'accès des applications d'IA.

Ce site web

geostrix.com ne dépose aucun cookie. C'est un site statique hébergé par Cloudflare ; l'hébergeur voit nécessairement votre adresse IP quand votre navigateur demande une page, comme pour tout site web. Le bouton de téléchargement interroge l'API publique de GitHub pour savoir quel programme d'installation est le plus récent et combien de fois GeoStrix a été téléchargé, donc votre navigateur contacte aussi api.github.com.

Mesure d'audience. Le site utilise Cloudflare Web Analytics pour compter les pages vues. Il ne dépose aucun cookie, ne stocke rien sur votre appareil, ne crée pas d'empreinte de votre navigateur et ne vous suit pas sur d'autres sites ; il indique de façon agrégée quelle page a été vue, le site d'origine, ainsi que votre navigateur, votre système d'exploitation et votre pays. L'application GeoStrix elle-même ne contient aucun outil d'analyse.
