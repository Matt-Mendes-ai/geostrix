Confidentialité

GeoStrix est une application de bureau qui fonctionne sur votre propre ordinateur. Elle n'a ni compte, ni connexion, ni outil d'analyse ou de télémétrie d'aucune sorte. Cette page décrit GeoStrix 0.1.69 et ce site web.

Ceci est une traduction de la politique de confidentialité en anglais. En cas de différence entre les deux versions, la version anglaise fait foi.

Ce que GeoStrix collecte

Rien. GeoStrix ne collecte, n'envoie et ne stocke aucune information personnelle, donnée d'utilisation, rapport de plantage ni télémétrie. L'application ne contient aucun code d'analyse, et aucun serveur de ce projet ne reçoit de données de sa part.

Rapports de problème. Aide → Signaler un problème crée un fichier zip dans votre dossier Téléchargements — ce que vous avez écrit, une image de la fenêtre de GeoStrix, les caractéristiques de votre système (versions, système d'exploitation, mémoire, carte graphique), les messages d'erreur récents (y compris les plantages d'écran des sessions précédentes, que GeoStrix conserve dans un petit fichier de son propre dossier de données sur votre ordinateur) et, si vous laissez la case cochée, le journal récent du moteur Python. Votre projet n'est inclus que si vous cochez cette option. GeoStrix n'envoie rien : il ouvre un courriel dans votre propre logiciel de messagerie, et le rapport ne part que si vous le joignez et l'envoyez.

Où se trouvent vos données

Les données de votre projet — têtes de sondage, mesures de déviation, descriptions, analyses, rasters et tout ce que vous importez — restent sur votre ordinateur : dans le fichier de projet que vous enregistrez, et dans un fichier d'enregistrement automatique dans le dossier de paramètres de GeoStrix. Elles ne sont jamais envoyées nulle part.

Mots de passe des bases de données. Par défaut, un mot de passe saisi dans Se connecter à la base de données n'est utilisé que pour la session en cours. Si vous cochez Mémoriser le mot de passe sur cet ordinateur, il est enregistré chiffré par le système d'exploitation (sous Windows, lisible uniquement par votre compte Windows sur cet ordinateur), dans le dossier de paramètres de GeoStrix — jamais dans le fichier de projet. L'oublier le supprime.

Le moteur Python utilisé pour la modélisation et les inversions, ainsi que le module optionnel de modélisation prédictive, fonctionnent sur votre ordinateur, n'écoutent que sur 127.0.0.1 et n'établissent aucune connexion sortante.

Ce site web

geostrix.com ne dépose aucun cookie. C'est un site statique hébergé par Cloudflare ; l'hébergeur voit nécessairement votre adresse IP quand votre navigateur demande une page, comme pour tout site web. Le bouton de téléchargement interroge l'API publique de GitHub pour savoir quel programme d'installation est le plus récent et combien de fois GeoStrix a été téléchargé, donc votre navigateur contacte aussi api.github.com.

Mesure d'audience. Le site utilise Cloudflare Web Analytics pour compter les pages vues. Il ne dépose aucun cookie, ne stocke rien sur votre appareil, ne crée pas d'empreinte de votre navigateur et ne vous suit pas sur d'autres sites ; il indique de façon agrégée quelle page a été vue, le site d'origine, ainsi que votre navigateur, votre système d'exploitation et votre pays. L'application GeoStrix elle-même ne contient aucun outil d'analyse.

Modifications et contact

Les modifications de cette politique accompagnent une nouvelle version et sont indiquées dans les notes de version. Questions : support@geostrix.com ou issues GitHub.
