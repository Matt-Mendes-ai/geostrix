Privacidad

GeoStrix es una aplicación de escritorio que funciona en tu propia computadora. No tiene cuentas, ni inicio de sesión, ni analítica o telemetría de ningún tipo. Esta página describe GeoStrix 0.1.56 y este sitio web.

Esta es una traducción de la política de privacidad en inglés. Si las dos versiones difieren, prevalece la versión en inglés.

Qué recopila GeoStrix

Nada. GeoStrix no recopila, envía ni almacena información personal, datos de uso, informes de fallos ni telemetría. No hay código de analítica en la aplicación ni ningún servidor de este proyecto que reciba datos de ella.

Reportes de problemas. Ayuda → Informar de un problema crea un archivo zip en tu carpeta de Descargas — lo que escribiste, una imagen de la ventana de GeoStrix, los datos de tu sistema (versiones, sistema operativo, memoria, tarjeta gráfica), los mensajes de error recientes y, si dejas la casilla marcada, el registro reciente del motor de Python. Tu proyecto se incluye solo si marcas esa opción. GeoStrix no envía nada: abre un correo en tu propia aplicación de correo, y el reporte solo se envía si tú lo adjuntas y lo mandas.

Dónde están tus datos

Los datos de tu proyecto — collares, mediciones de desviación, logueos, ensayos, rásteres y todo lo que importes — se quedan en tu computadora: en el archivo de proyecto que guardas y en un archivo de autoguardado en la carpeta de configuración de GeoStrix. Nunca se suben a ningún lugar.

Contraseñas de bases de datos. Por defecto, una contraseña escrita en Conectar a base de datos se usa solo durante esa sesión. Si marcas Recordar la contraseña en este equipo, el sistema operativo la guarda cifrada (en Windows, legible solo por tu cuenta de Windows en esa computadora) en la carpeta de configuración de GeoStrix — nunca en el archivo de proyecto. Olvidarla la elimina.

Como al visitar cualquier sitio web, estas solicitudes muestran tu dirección IP al servicio contactado, que tiene su propia política de privacidad. No se envía ningún identificador tuyo ni de tu proyecto. El corrector ortográfico integrado está desactivado, así que no se descarga ningún diccionario. Si no usas ninguna de estas funciones, GeoStrix no hace ninguna conexión de red.

El motor de Python que se usa para el modelamiento y las inversiones, y el complemento opcional de modelamiento predictivo, funcionan en tu computadora, solo escuchan en 127.0.0.1 y no hacen conexiones salientes.

Este sitio web

geostrix.com no usa cookies. Es un sitio estático alojado en Cloudflare; el servidor web necesariamente ve tu dirección IP cuando tu navegador pide una página, como en cualquier sitio web. El botón de descarga consulta la API pública de GitHub para saber cuál es el instalador más reciente y cuántas veces se ha descargado GeoStrix, así que tu navegador también se conecta a api.github.com.

Conteo de visitas. El sitio usa Cloudflare Web Analytics para contar las páginas vistas. No usa cookies, no guarda nada en tu dispositivo, no identifica tu navegador por huella digital ni te sigue por otros sitios; informa qué página se vio, el sitio de referencia, y tu navegador, sistema operativo y país, de forma agregada. La aplicación GeoStrix en sí no tiene analítica de ningún tipo.

Cambios y contacto

Los cambios a esta política llegan con una nueva versión y se indican en las notas de la versión. Preguntas: support@geostrix.com o issues en GitHub.
