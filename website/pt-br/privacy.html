Privacidade

O GeoStrix é um aplicativo para desktop que roda no seu próprio computador. Ele não tem contas, nem login, nem análise de uso ou telemetria de nenhum tipo. Esta página descreve o GeoStrix 0.1.66 e este site.

Esta é uma tradução da política de privacidade em inglês. Se as duas versões forem diferentes, vale a versão em inglês.

O que o GeoStrix coleta

Nada. O GeoStrix não coleta, envia nem armazena informações pessoais, dados de uso, relatórios de falha ou telemetria. Não há código de análise de uso no aplicativo nem nenhum servidor deste projeto que receba dados dele.

Relatórios de problema. Ajuda → Relatar um problema cria um arquivo zip na sua pasta Downloads — o que você escreveu, uma imagem da janela do GeoStrix, os dados do seu sistema (versões, sistema operacional, memória, placa de vídeo), as mensagens de erro recentes (incluindo falhas de tela de sessões anteriores, que o GeoStrix guarda num pequeno arquivo na própria pasta de dados do seu computador) e, se você deixar marcado, o log recente do motor Python. Seu projeto só é incluído se você marcar essa opção. O GeoStrix não envia nada: ele abre um e-mail no seu próprio aplicativo de e-mail, e o relatório só é enviado se você o anexar e enviar.

Onde ficam seus dados

Os dados do seu projeto — bocas de furo, medidas de desvio, descrições, análises, rasters e tudo o que você importar — ficam no seu computador: no arquivo de projeto que você salva e em um arquivo de salvamento automático na pasta de configurações do GeoStrix. Eles nunca são enviados para lugar nenhum.

Senhas de banco de dados. Por padrão, uma senha digitada em Conectar ao banco de dados é usada só naquela sessão. Se você marcar Lembrar a senha neste computador, ela é guardada criptografada pelo sistema operacional (no Windows, legível só pela sua conta do Windows naquele computador), na pasta de configurações do GeoStrix — nunca no arquivo de projeto. Esquecer a remove.

Como ao visitar qualquer site, essas solicitações mostram seu endereço IP ao serviço contatado, que tem sua própria política de privacidade. Nenhum identificador seu ou do seu projeto é enviado. O corretor ortográfico integrado está desativado, então nenhum dicionário é baixado. Se você não usar nenhum desses recursos, o GeoStrix não faz nenhuma conexão de rede.

O motor Python usado na modelagem e nas inversões, e o complemento opcional de modelagem preditiva, rodam no seu computador, escutam apenas em 127.0.0.1 e não fazem conexões de saída.

Este site

O geostrix.com não usa cookies. É um site estático hospedado na Cloudflare; o servidor necessariamente vê seu endereço IP quando o navegador pede uma página, como em qualquer site. O botão de download consulta a API pública do GitHub para saber qual é o instalador mais recente e quantas vezes o GeoStrix foi baixado, então o seu navegador também se conecta a api.github.com.

Contagem de visitas. O site usa o Cloudflare Web Analytics para contar as visualizações de página. Ele não usa cookies, não guarda nada no seu dispositivo, não identifica o seu navegador por impressão digital nem segue você em outros sites; informa qual página foi vista, o site de origem, e o seu navegador, sistema operacional e país, de forma agregada. O aplicativo GeoStrix em si não tem nenhuma análise de uso.

Alterações e contato

As alterações nesta política vêm com uma nova versão e são indicadas nas notas da versão. Dúvidas: support@geostrix.com ou issues no GitHub.
