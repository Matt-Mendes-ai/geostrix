Privacy

GeoStrix is a desktop application that runs on your own computer. It has no accounts, no sign-in, and no analytics or telemetry of any kind. This page describes GeoStrix 0.1.59 and this website.

What GeoStrix collects

Nothing. GeoStrix does not collect, send or store personal information, usage data, crash reports or telemetry. There is no analytics code in the application and no server run by this project that receives data from it.

Problem reports. Help → Report a Problem makes a zip file in your Downloads folder — what you wrote, a picture of the GeoStrix window, your system details (versions, operating system, memory, graphics card), recent error messages and, if you leave it ticked, the Python engine's recent log. Your project is included only if you tick it. GeoStrix sends nothing: it opens an email in your own email app, and the report goes only if you attach it and send it.

Where your data lives

Your project data — collars, surveys, logs, assays, rasters and everything else you import — stays on your computer: in the project file you save, and in an autosave file in GeoStrix's own settings folder. It is never uploaded anywhere.

Database passwords. By default, a password typed in Connect to database is used for that session only. If you tick Remember the password on this computer, it is stored encrypted by the operating system (on Windows, readable only by your Windows account on that computer), in GeoStrix's settings folder — never in the project file. Forget it removes it.

Like visiting any website, these requests show your IP address to the service contacted, which has its own privacy policy. No identifier for you or your project is sent. The built-in spell checker is off, so no dictionary is downloaded. If you use none of these features, GeoStrix makes no network connections at all.

The Python engine used for modelling and inversions, and the optional predictive-modelling add-on, run on your computer, listen only to 127.0.0.1, and make no outbound connections.

This website

geostrix.com sets no cookies. It is a static site hosted by Cloudflare; the web host necessarily sees your IP address when your browser asks for a page, as with any website. The download button asks GitHub's public API which installer is newest and how many times GeoStrix has been downloaded, so your browser also contacts api.github.com.

Visitor counts. The site uses Cloudflare Web Analytics to count page views. It sets no cookies, stores nothing on your device, does not fingerprint your browser and does not follow you across other sites; it reports which page was viewed, the referring site, and your browser, operating system and country, in aggregate. The GeoStrix application itself has no analytics of any kind.

Changes and contact

Changes to this policy come with a release and are noted in the release notes. Questions: support@geostrix.com or GitHub issues.
